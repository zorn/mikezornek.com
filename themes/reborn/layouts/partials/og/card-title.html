Everything else renders `.Title` as authored, so authored titles stay authoritative. See decisions/og-images.md. Note this affects the card image only. The `og:title` meta tag still carries the page's real title, because that is what a reader is choosing to click. */ -}} {{- $title := .Title -}} {{- if .IsHome -}} {{- /* The home page title is deliberately "Mike Zornek" (see decisions/page-metadata.md), which is the same words as the wordmark printed directly above it on the card. */ -}} {{- $title = "Elixir, Phoenix, and the craft of shipping software" -}} {{- else if and (eq .Kind "term") (eq .Data.Plural "tags") -}} {{- /* `capitalizeListTitles: false` keeps tag terms as authored, so these titles are bare lowercase words.
