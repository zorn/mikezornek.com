{{- /* Heading render hook (see issue #194). Hugo already emits GitHub-style slug `id`s on every content heading, so the deep-link targets exist. This hook adds the visible affordance: a `#` marker on blog-post h2/h3 that copies the section's URL (the clipboard copy is wired up in themes/reborn/assets/js/main.js). The anchor is emitted as an EMPTY ; its `#` glyph comes from CSS (`.heading-anchor::before`), not DOM text.
