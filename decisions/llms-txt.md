# Generate /llms.txt, and be honest that it may do nothing

The site publishes `/llms.txt` in the format described at
<https://llmstxt.org>: an H1, a blockquote summary, then H2 sections of
annotated links. It is generated by a Hugo output format from data the site
already keeps, not hand-written.

**Start with the caveat, because it is the most important part of this
decision: no major AI vendor documents consuming `llms.txt`.** It is a
convention pushed largely by the documentation-tooling world, and the crawler
operators have not committed to it. Anyone presenting it as a proven channel is
guessing. The case for publishing one is cheap optionality, not measured
return.

Given that, the whole question was how little it could cost.

**Why generated rather than hand-written:** `data/start-here.yaml` is already a
hand-ranked list of the most trust-building posts, each with an editorial note
explaining why a newcomer should read it. That is precisely the payload this
format asks for, written for an entirely different reason. Generating means the
file reuses curation that already exists, and cannot go stale the next time a
post ships. A hand-written copy would be wrong within a month and nobody would
notice, because nobody reads their own `llms.txt`.

**Why it was built last:** because the value is unproven, this was sequenced
after every other piece of the search work in #144, on the explicit
understanding that cutting it would lose nothing. It survived because it came
in at one template.

## Considered and rejected

- **Skip it entirely.** Defensible, and the honest runner-up. Rejected because
  the marginal cost over "skip" turned out to be a single template that reads
  existing data.
- **A hand-authored `static/llms.txt`.** Better prose, immediate staleness.
  The Start Here notes are already good prose written by the same person.
- **Dumping every post into it.** The format's value is curation. A 447-item
  list is the sitemap with extra steps, and the sitemap already exists.

## Consequences

- The file lists the Start Here entries with their editorial notes, the 20 most
  recent posts, the standalone pages, and the feed and sitemap URLs.
- `/random/` and `/search/` are excluded: one is a redirect and the other is a
  search index, and neither is worth a model's attention.
- Like `ogmanifest`, the output format sets `notAlternative: true` so it stays
  out of `.AlternativeOutputFormats` and off the `<link rel=alternate>` tags in
  the head. It is a machine artifact fetched at a well-known path, not a
  representation of the homepage.
- If a vendor ever documents reading this file, revisit the contents against
  whatever they actually specify. Until then, do not spend more time on it.
